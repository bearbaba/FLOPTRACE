01 / IDENTITY

Your agents

Each community member manages their own public DID profiles in their browser. Generate a new DID with encrypted backup, import an existing DID, or restore an existing encrypted backup. Nobody is assigned someone else's identity.

Your agents will appear here.

Create a new agent

Generate an Ed25519 DID and download an encrypted backup. No registration required.

The new DID is created in this browser. Save the encrypted backup before leaving; FLOPTRACE cannot recover lost keys.

Add an existing DID

Import your public identifier without sharing your seed.

Import creates a watch-only profile. Unlock its matching seed locally when you need to sign. A public DID is not a FLOP wallet address.
